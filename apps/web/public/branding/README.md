# LoLGamerLand branding

Owner-supplied artwork: https://chatgpt.com/s/m_6acbb3f3989881919d3a468fb424fef3

The source is a 1254 × 1254 PNG containing the logo above the app icon. These assets preserve the supplied artwork; no illustration was redrawn.

- `logo.png`: the upper logo, cropped to 1154 × 676 at (50, 32).
- `icon-512.png`: the lower icon, cropped to 450 × 450 at (402, 714) and resized to 512 × 512.
- `icon-192.png`, `apple-touch-icon.png`, `favicon.png`: 192, 180 and 48 pixel copies of the lower icon.
- `icon-maskable-512.png`: the icon resized to 384 × 384, centered on a 512 × 512 blue background to accommodate launcher masks.

The web manifest uses the ordinary and maskable icons for Android. The HTML head declares the 180 pixel Apple touch icon for iOS and the 48 pixel browser favicon. All asset links are relative so they work under the repository's GitHub Pages path.
