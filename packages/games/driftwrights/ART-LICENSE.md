# Original Driftwrights artwork

The floating-island atlas in `apps/web/src/games/driftwrights/island-atlas.png` was generated originally for this implementation. The board geometry, hearths, hubs, sky links, resource symbols and associated visual design beside it were created for this repository. No artwork from a published game or gaming site is included.
