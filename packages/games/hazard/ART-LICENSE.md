# Original Hazard artwork

The atlas of the Meridian (the hex grid in `src/atlas.ts` and the drawing built from it in `apps/web/src/games/hazard/`), the charter faces, the troop tokens, the dice, the cover and the thumbnail were created for this repository. No artwork, map drawing or layout from a published game or gaming site is included.
